# Kasoti

A hidden-name guessing game: **Seekers** ask yes/no questions, **Keepers** answer. Find the secret famous person or place before time runs out.

* 👥 **Play with friends** — host a game, share the code/link, two teams, turns, hints, chat & reactions (no sign-up).
* 🤖 **Play with AI** — you're the Seeker; an **offline** AI Keeper knows famous people and places of **India and Pakistan**. No API key, no internet.

```bash
npm install
npm start        # http://localhost:3000
npm test         # validates the data set and runs all tests
```
